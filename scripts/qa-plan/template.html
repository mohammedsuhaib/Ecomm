Release sign-off

The minimum set to run before any production release — use the Release gate filter to isolate it.

  1. Minimum set to run before any production release:
  2. TC-ENV-002, TC-ENV-005, TC-ENV-006 — clean deploy, correct API URL, full smoke loop.
  3. TC-SEC-011, TC-SEC-012, TC-SEC-013 — seeded credentials rotated, no secret or cost-price leakage, OTP gated.
  4. TC-CHK-001/002/003/012/013 — checkout, minimum order, no duplicate orders.
  5. TC-ADM-003/004/005 — order state machine and OTP-gated delivery.
  6. TC-INV-006/007 — stock released on cancel, committed on delivery.
  7. TC-TAX-002/007/008 — GST arithmetic, frozen invoices, statutory format.
  8. TC-DLV-003/004 — rider handover with OTP.
  9. TC-ORD-008/009 — cancellation window honoured.
  10. TC-NOTIF-001 (keys unset) or TC-NOTIF-004/009 (keys set).
  11. TC-I18N-002 — no missing translations.
